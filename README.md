# Rock Paper Scissors Game

A simple Rock-Paper-Scissors game built with Python.

## Features

* Play against the computer
* Random computer choices using Python's `random` module
* ASCII art for Rock, Paper, and Scissors
* Win, Lose, and Draw detection
* Input validation for invalid choices

## Technologies Used

* Python 3
* Random Module

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd rock-paper-scissors
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## How to Play

* Enter `0` for Rock
* Enter `1` for Paper
* Enter `2` for Scissors

The computer will randomly choose Rock, Paper, or Scissors and the winner will be displayed.
